# kaiz-upscale

A simple Node.js package for upscaling images 2x.

## Installation :
```bash
npm i kaiz-upscale
```

## Usage :
```js
const kaiz = require('kaiz-upscale');

const imageUrl = 'https://example.com/image.jpg';
const outputPath = './upscaled-image.jpg';

kaiz.upscale(imageUrl, outputPath);
```
## Output Example :
```js
{
    ./upscaled-image.jpg
}
```
